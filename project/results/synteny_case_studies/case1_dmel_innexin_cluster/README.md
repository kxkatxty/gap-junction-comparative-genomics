# Case Study 1: Drosophila innexin cluster synteny

Compares home-genome flanking genes around **ogre**, **Inx2**, and **Inx3**.

## Regions
- **Proximal cluster** (proximal_cluster_6.8-7.1Mb): ogre locus 1 vs Inx2 locus 1
- **Distal cluster** (distal_cluster_20.5-21.0Mb): ogre locus 2 vs Inx2 locus 3 vs Inx3 locus 2
